# 仓鼠小窝

一个原生 HTML、CSS、JavaScript 的治愈系 2D 电子宠物小游戏，无框架、无需构建、无外部网络依赖。

直接用浏览器打开 `index.html`。Chrome、Edge、Firefox 的现代版本均可运行；也可用任意静态文件服务器。

首次选择仓鼠并命名，进入房间后可喂食、喝水、抚摸、玩耍、睡觉、清理。完成每日任务和有效照顾可以赚取金币，用于购买食物、玩具和家具。在布置模式中拖动家具，点击家具收回，再从物品箱摆放。地面家具禁止重叠，仓鼠会绕开家具行走。

存档保存在浏览器 localStorage。设置里支持 JSON 导出、导入、改名、减少动态效果、撤销布置与重新开始。关闭浏览器后最多结算 2 小时的属性变化，无死亡或失败惩罚。不同浏览器及不同页面地址的存档独立；切换之前请导出存档。

声音默认关闭。点击右上角音符开启轻柔的程序合成音效与间歇提示音，无连续背景乐曲。

## 项目

- `index.html`：界面与房间结构
- `css/style.css`：绘本风格、响应式布局和动画
- `js/game.js`：集中配置、状态、寻路、互动、经济、商店、装饰、存档

首版为方便本地直接运行，将游戏逻辑放在一个普通脚本中；内部按函数组织，不使用 ES Module / fetch。角色和家具为本地内联 SVG，不需要下载图片。

## 浏览器检查

检查脚本需要 Python 与 Playwright，仅开发验证需要，游戏本身不依赖它们。

```bash
python tests/browser_smoke.py
python tests/storage_and_layout.py
```

脚本会启动临时本地静态服务器，真实点击界面，检查互动、存档和移动端布局。截图等检查产物输出到 `checks/`，不提交仓库。云端 Chromium 策略禁止直接打开 file URL，因此本次浏览器验证通过本地 HTTP 执行。
